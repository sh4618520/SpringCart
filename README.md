# 🛒 SpringCart (쇼핑몰 클론 코딩 프로젝트)

스프링 부트(Spring Boot)와 리액트(React)를 활용하여 빌드한 풀스택 쇼핑몰 토이 프로젝트입니다.

## 🛠️ Tech Stack

### Backend
- **Project:** Gradle - Groovy
- **Language:** Java 21
- **Framework:** Spring Boot 4.0.6
- **Database:** JPA / Hibernate, MYSQL

### Frontend
- **Language:** TypeScript
- **Library:** React (Vite)

## 🚀 시작하기

### Backend
```bash
cd backend
./gradlew bootRun
```

### Frontend
```bash
cd frontend
npm install
npm run dev
